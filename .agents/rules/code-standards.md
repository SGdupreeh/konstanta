# Стандарты разработки и код-стайл проекта

Данные правила обязательны для всех агентов при модификации файлов в репозитории.

## 1. HTML и семантика
- Использовать строгий семантический HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`).
- Ровно один `<h1>` на страницу.
- Запрещены inline-стили `style="..."` (за исключением динамических CSS-переменных, генерируемых скриптом).
- Все формы ввода должны содержать явные `<label for="id">` и атрибуты `autocomplete`.

## 2. Стилизация и CSS
- Использовать CSS Custom Properties для цветов, отступов и радиусов.
- Запрещено переопределять стили через `!important` (только для служебных классов вроде `.u-hidden`).
- Мобильная адаптивность: Mobile-first или Desktop-down, но обязательно тестирование на контрольных точках: 360px, 768px, 1024px, 1440px.
- Анимации: только через `transform` и `opacity` с обязательной поддержкой `@media (prefers-reduced-motion: reduce)`.

## 3. JavaScript
- Нативный модульный JavaScript (ES6+) без добавления тяжелых сторонних фреймворков (если не было явного запроса пользователя).
- Чистая архитектура данных (разделение `site-data.js` и представления `site-pages.js`).
- Все обработчики событий должны корректно очищаться или вешаться методом делегирования.
- Отсутствие несанкционированных обращений к внешним скриптам/CDN без настройки CSP.
