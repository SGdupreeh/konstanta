# Регламент оптимизации графики и медиа

## 1. Векторные изображения (SVG)
1. **Очистка метаданных:**
   - Удаление лишних тегов редакторов: `<metadata>`, `xmlns:sketch`, `data-name`, пустых `<g></g>`.
   - Замена жестких `width` и `height` на атрибут `viewBox="0 0 W H"` для адаптивного масштабирования.
2. **Оптимизация цветов:**
   - Использование `fill="currentColor"` или CSS-переменных для монохромных иконок вместо жестко закодированных `#000000`.

## 2. Фотографии объектов и галереи (WebP / AVIF)
1. **Современные форматы:**
   - Все новые фотографии должны быть конвертированы в `.webp` или `.avif` с качеством 80–85% (визуально неотличимо от 100% JPG, но вес меньше в 3–5 раз).
2. **Адаптивная разметка через `<picture>`:**
```html
<picture>
  <source type="image/avif" srcset="photo.avif">
  <source type="image/webp" srcset="photo.webp">
  <img src="photo.jpg" 
       alt="Остекление фасада школы №123" 
       width="800" 
       height="600" 
       loading="lazy" 
       decoding="async">
</picture>
```
3. **Защита от сдвигов макета (CLS = 0):**
   - Каждое изображение ОБЯЗАНО иметь явные атрибуты `width` и `height` либо CSS-свойство `aspect-ratio: 16 / 9;`.
   - Никогда не оставлять `<img>` без пропорций, иначе страница будет «прыгать» при подгрузке фото.

## 3. Стратегия загрузки изображений
1. **Изображение первого экрана (Hero/Cover):**
   - Не использовать `loading="lazy"`.
   - Использовать `fetchpriority="high"` для ускорения LCP (Largest Contentful Paint).
2. **Изображения ниже первого экрана (галереи, карточки):**
   - Всегда указывать `loading="lazy"` и `decoding="async"`.
