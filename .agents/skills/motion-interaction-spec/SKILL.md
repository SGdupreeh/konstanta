# Стандарт микроанимаций и кинематики (60 FPS Motion)

## 1. Аппаратное ускорение (GPU Composition)
1. **Разрешенные анимируемые свойства:**
   - Строго ТОЛЬКО `transform` (translate, scale, rotate) и `opacity`.
2. **Категорически запрещено анимировать:**
   - `width`, `height`, `top`, `left`, `margin`, `padding`, `box-shadow` (вызывают принудительный перерасчет разметки — Layout Thrashing и просадку кадров).

## 2. Физика кривых скорости (Easing) и длительности
- **Микро-отклики (hover кнопок, фокус инпутов):** `150ms ease-out`
- **Открытие модалок и боковых панелей:** `250–300ms cubic-bezier(0.16, 1, 0.3, 1)` (естественный разгон и мягкое демпфирование в конце).
- **Сворачивание / закрытие:** `150–200ms cubic-bezier(0.7, 0, 0.84, 0)` (более быстрое исчезновение).

## 3. Обязательная адаптация к доступности
Каждый файл анимаций ОБЯЗАН содержать сброс для пользователей с чувствительным вестибулярным аппаратом:
```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```
