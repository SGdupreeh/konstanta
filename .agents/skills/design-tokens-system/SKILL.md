# Стандарт архитектуры CSS-токенов

## 1. Иерархия токенов
Все стили разделяются на 3 слоя:
1. **Глобальные (Global Primitives):** чистые значения (например, `--blue-500: #1d4ed8;`).
2. **Семантические (Semantic Tokens):** роли элементов (например, `--color-primary: var(--blue-500);`).
3. **Компонентные (Component Tokens):** переменные конкретного блока (например, `--btn-primary-bg: var(--color-primary);`).

## 2. Шкала отступов (Spacing Scale)
Используется 4px/8px шаг. Запрещены случайные значения (`11px`, `19px`, `23px`):
```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 20px;
  --space-6: 24px;
  --space-8: 32px;
  --space-10: 40px;
  --space-12: 48px;
  --space-16: 64px;
}
```

## 3. Матрица состояний интерактивных компонентов
Любая кнопка, ссылка, инпут или карточка обязаны описывать состояния:
1. `:default` — исходное состояние.
2. `:hover` — наведение мыши (плавный переход цвета/тени, 150ms).
3. `:focus-visible` — клавиатурный фокус с четким контрастным контуром.
4. `:active` — момент клика/нажатия (легкое вдавливание `scale(0.98)`).
5. `[disabled] / :disabled` — неактивное состояние (`opacity: 0.5; pointer-events: none; cursor: not-allowed;`).
6. `.is-loading` — состояние отправки/загрузки со спиннером.
7. `.has-error` — состояние ошибки валидации с поясняющим текстом.
