# Константа — GitHub Pages

Эта папка подготовлена для публикации статического сайта через GitHub Pages.

1. Создайте на GitHub новый репозиторий.
2. Загрузите содержимое этой папки в корень репозитория: `index.html` должен находиться в корне.
3. В настройках репозитория откройте `Settings → Pages`.
4. В разделе публикации выберите ветку `main` и папку `/ (root)`.
5. Сохраните настройки и дождитесь адреса сайта.

В комплекте только публичные материалы сайта: HTML, CSS, JavaScript, логотип и используемые фотографии. Архивы, исходные фото-коллекции и служебные инструменты исключены.
